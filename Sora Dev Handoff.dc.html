1 · Architecture at a glance

Clients: SwiftUI (iOS 17+) and Jetpack Compose (Android 8+), thin — all story/affirmation generation server-side.
Backend: Supabase or Firebase (auth, Postgres/Firestore, storage for audio) + a worker queue for story-generation jobs.
AI: LLM API for story/letter/affirmation text · ElevenLabs for TTS + instant voice cloning · pipeline: profile context → prompt template → text → TTS → cached MP3 in storage/CDN.
Subscriptions: RevenueCat (both stores, one SDK) · Analytics: Amplitude or PostHog + RevenueCat webhooks.
Notifications: local scheduling for rituals; push (APNs/FCM) for Today's-Moment-ready and the day-5 trial reminder (contractual — see §5).

5 · Monetization integration

RevenueCat offering: weekly $6.99 / 7-day trial (default) + annual $49.99 surfaced at the day-5 reminder and in Profile.
Day-5 reminder is a product promise — shown on the paywall UI. Implement as a server-scheduled push + in-app banner; if pushes are disabled, in-app banner is mandatory on next open. Breaking this promise breaks the entire trust positioning.
Cancel flow: Profile → Manage subscription deep-links to store-native management (two taps). No retention dark patterns — the analysis shows honesty is the conversion strategy.
Referral: RevenueCat promotional entitlements — giver and receiver each get 7 days on redemption. Attribute via invite links (Branch or App Store/Play referrer).
